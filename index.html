Инструкция «Clean System»

Безопасное обновление и переход на Extra-версию

  1. Загрузите ваше сохранение в игре.
  2. Откройте MCM меню SexLab и перейдите на последнюю вкладку.
  3. Нажмите кнопку Export Configuration (Экспорт настроек).
  4. Нажмите кнопку Clean System (Очистка системы).
  5. Подождите 2–3 минуты, не закрывая игру, пока процесс очистки не завершится.
  6. Нажмите Import Configuration (Импорт настроек) для возврата ваших опций.
  7. Сделайте новое ручное сохранение игры.
Важно: Не пропускайте этот шаг при обновлении на Extra-версию, чтобы избежать сбоев масштаба персонажей (уменьшение до микро-размеров).
